# LifeLink – Organ Donation Awareness Website

LifeLink is a simple, responsive front-end website created as a college mini project for **Fundamentals of Full Stack**. It introduces visitors to organ donation and encourages them to seek reliable guidance from authorised healthcare professionals and official organisations.

> **Important:** This is an educational demo only. It is not a donor registry, medical service, or donor-recipient matching platform. It does not register donors, determine medical eligibility, or transmit or store form entries.

## Features

- **Home section:** Introduces LifeLink and provides navigation to the main sections.
- **Organ donation awareness:** Shares introductory information and encourages informed decisions.
- **Guidance steps:** Recommends trusted information, qualified professionals, and official procedures.
- **Frequently asked questions:** Answers common questions about the purpose and limitations of the demo.
- **Sample contact form:** Demonstrates basic form fields and a notice interaction; submissions are not sent or saved.
- **Responsive design:** Uses CSS media queries to adapt the layout to smaller screens.
- **Accessibility basics:** Includes semantic sections, labelled form fields, keyboard focus indicators, and readable navigation.

## Technologies Used

- HTML5
- CSS3

The website is a static front-end project. It does not require a database, backend server, or account system.

## How to Run Locally

1. Download or clone this repository.
2. Make sure `index.html` and `style.css` are in the same folder.
3. Open `index.html` in a modern web browser such as Chrome, Edge, or Firefox.

No installation or build step is required.

## Run with GitHub Pages (Optional)

1. Upload `index.html`, `style.css`, and `README.md` to your GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under the build/deployment settings, choose **Deploy from a branch**.
5. Select your main branch and the repository root (`/`) folder, then save.
6. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.

## Limitations

- The website provides general awareness information only; it is not medical advice.
- It does not register donors or recipients, check eligibility, or match donors with recipients.
- The contact form is a demonstration only. It does not send or store the entered information.
- It does not include a backend, database, authentication, or live donor directory.
- For real-world registration or medical questions, consult authorised organisations and qualified healthcare professionals.
